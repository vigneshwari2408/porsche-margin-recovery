# Porsche 2026 Margin Recovery: portfolio website

A static, dependency-free case-study site (HTML, CSS and vanilla JavaScript). There is no build step.
It presents Vigneshwari Nalla's Company Lens project, which tests whether Porsche's H1 2026 margin
recovery is real. The project uses only Porsche AG's public disclosures and is reconciled across SQL,
Excel and Power BI.

## Status
Final. All sections, interactions and the six final Power BI screenshots are in place.
The only thing still to add is the public links (see "Before you publish").

## Run locally
    python3 -m http.server 8000     # then open http://localhost:8000
Open it through a local server rather than by double-clicking `index.html`, so the screenshots load the same way they will once deployed.

## Deploy
- **GitHub Pages:** this folder is the repository's `/docs` folder, so GitHub Pages can publish it directly: Settings > Pages > Deploy from a branch > `main` / `/docs`. The `.nojekyll` file is already included.
- **Netlify:** drag the folder onto app.netlify.com/drop, or connect the repository with no build command and publish directory `.`.
- **Vercel:** run `vercel` in this folder and choose the framework preset "Other", with no build command.

## Before you publish
1. **Links:** paste the real URLs into `assets/js/links.js` once the repository is public. Each empty entry shows as "Link not yet published", so no card ever points to an address that does not exist. Use full URLs of the form `https://github.com/<user>/<repository>/blob/main/<path>`. The paths in this repository are: `Porsche_Margin_Recovery_Report.md`, `Case_Study.md`, `powerbi/`, `sql/`, `excel/PCL_05_Porsche_Margin_Model_FINAL.xlsx` and `presentation/Porsche_Margin_Recovery_Deck.pdf`.
2. **Images:** see "Image rights" below. A replacement must keep the same file name.
3. **Your role:** the six statements in "My role" describe your contribution. Read them once more before publishing.

How they appear on the site:
- The story itself uses the site's own charts. Only page 6 (QA and Lineage) is shown inline, at the end of the QA chapter, as evidence, in a display-style frame at its native aspect ratio.
- All six pages stay available: the Power BI card in "Explore the work" has a "Preview the six pages" button that opens the gallery, next to the dashboard link once it is published.
- Select the QA screenshot or the preview button to open the gallery. The gallery has previous and next buttons, arrow keys, zoom (buttons, the + and − keys, or double-click), drag to pan, and Escape to close.
- The QA page's frame and caption state the result, ALL 388 QA CHECKS PASS (Power BI vs SQL mart). That label is built from the QA count in `data.js` and only appears when every check passes.
- A frame stays hidden if its file is missing, so a broken image is never shown.

## Where the numbers come from
`assets/js/data.js` is generated by [`../tools/build_site_data.py`](../tools/build_site_data.py) from the final reconciled outputs: [`../model/key_values.json`](../model/key_values.json) and the 17 CSVs loaded by the .pbix ([`../data/powerbi/`](../data/powerbi/)). No figure is typed by hand in the page scripts. To regenerate, from the repository root:

## Design and interaction notes
- **Hero:** layered from back to front as red studio, giant PORSCHE lettering, the car, smoke, then the title. The pointer and scrolling move each layer at a different speed.
- **The tail-light bar** is the recurring element: the hero light, the reading-progress line, the chapter dividers and the chart baselines.
- **Navigation:** the chapter numbers 01 to 07 plus a tachometer whose needle follows reading progress.
- **Interactions by section:**
  - Overview: KPI cards highlight their line in the margin chart.
  - EBIT: the bridge is built row by row as you scroll, with a stage indicator above it.
  - R&D: a dial follows the capitalisation rate through the half-years.
  - Commercial: the volume and ASP equation highlights its bars in the revenue bridge and the unit and price charts, and mix rows isolate on hover.
  - Cash and guidance: a scenario console for the 27 guidance combinations, labelled "Arithmetic only — not forecasts — no probabilities".
  - QA: a disc fills to the real 388/388, then the checks light up in order.
  - Explore the work: seven cards (Power BI, report, presentation, Excel, SQL, case study, GitHub repository) that link to the files once `links.js` is filled in.
- **Motion:** decorative motion (smoke, fog, light streaks) pauses when off-screen, and all motion switches off for visitors who set "reduce motion".
